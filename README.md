# 📦 Nexora – Product Management Dashboard

A modern and responsive Product Management Dashboard built with React.js and Tailwind CSS. Nexora helps users manage product inventory through an intuitive interface with product management, search, filtering, sorting, and dashboard statistics.

## 🚀 Project Overview

Nexora is a frontend product management application designed to simplify inventory management.

The application provides a centralized dashboard where users can view product statistics, manage products, explore categories, and organize inventory efficiently.

## ✨ Features

- **Dashboard Overview** – View inventory statistics and recently added products.
- **Product Management** – Add, edit, view, and delete products.
- **Category Management** – Explore products across different categories.
- **Search Functionality** – Search products by name.
- **Category Filtering** – Filter products based on their categories.
- **Price Range Filtering** – Find products within a specific price range.
- **Sorting** – Sort products by price and product name.
- **Dark & Light Mode** – Switch between different visual themes.
- **Local Storage** – Preserve product data using browser local storage.
- **Responsive Design** – Optimized for desktop, tablet, and mobile screens.

## 🛠️ Technologies Used

| Technology | Purpose |

## ⚙️ Installation & Setup

Follow these steps to run the project locally.

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Navigate to the project directory

```bash
cd product-management-dashboard
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

### 5. Open in browser

Visit the local URL displayed in your terminal, usually:

```text
http://localhost:5173
```
